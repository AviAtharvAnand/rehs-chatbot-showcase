### Disclaimers

<p style={{ fontWeight: 'bold' }}>
  The National Research Platform currently has no storage that is suitable for <strong>HIPAA</strong>, <strong>PID</strong>, <strong>FISMA</strong>, <strong>FERPA</strong>, or protected data of any kind. Users are not permitted to store such data on NRP machines.
</p>
